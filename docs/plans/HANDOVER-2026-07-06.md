## What shipped (all on `main`)

- **CLI machine contract** — `--url` normalizes to `/v1`; `--workspace` on client
  verbs; `cards patch --title`; per-verb `--help`; class-based exit codes (3/4/5);
  `list --include=links,comments`; bare `cards` prints usage.
- **Events reliability** — a persist:true condition's fired-marker and its event
  append now commit atomically (`MarkConditionFiredAndAppend`), closing the
  crash-window that could lose an escalation forever. The hook supervisor drains
  in-flight subprocesses (process-group kill) on shutdown.
- **Attachments end-to-end** — `internal/artifacts` wired through HTTP
  (`POST /v1/cards/{id}/artifacts/{field}`, `GET /v1/artifacts/*`), `cards
  attach`, MCP (`attach_artifact`/`get_artifact`, base64), and `/ui` card detail
  (thumbnail/download). Serve route resolves traversal/symlink/absolute → 404.
- **Canonical JSONL** — `cards export --state-only` writes the git-portable card
  state (mutation log stays SQLite-owned; only `card_deleted` tombstones ride
  along). The board is committed at `examples/demo-workspace/backlog.jsonl`, and
  `internal/docaudit` fails CI (as a Go test) if any `docs/ROADMAP.md` card id
  doesn't resolve against it. A `parent` link type + hierarchy docs were added.
- **Versioning/release** — `cards version`, `CHANGELOG.md` (v0.1.0),
  `.github/workflows/release.yml` (cross-platform binaries + GitHub Release on a
  `v*` tag), README Releases section. Pipeline validated locally end-to-end.
- **Design/decision docs** — `docs/design/OUTBOX-GONOGO.md` (the gate + verdict)
  and `docs/design/SUBSCRIBERS.md` (the deferred outbox/webhook RFC).

Debt ledger reconciled against HEAD; `docs/ROADMAP.md` updated (attachments →
